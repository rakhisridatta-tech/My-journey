# Week 1 Review

## What I Learned

During the first week of my journey, I focused on learning through practical tasks rather than only reading theory. I worked with development tools, web technologies, Git/GitHub, and project documentation.

One of the most important lessons was understanding that consistent practice is more valuable than trying to learn everything at once.

## What I Built

I completed multiple practical exercises as part of my learning journey. These exercises helped me understand how individual concepts can be applied to real projects.

I also practiced maintaining my work in a GitHub repository and documenting my progress through learning notes and daily journals.

## Challenges

One of my main challenges was getting comfortable with Git and GitHub workflows. Understanding concepts such as staging, commits, branches, and pushing changes required practical practice.

Another challenge was organizing my work properly so that my repository remained easy to understand and navigate.

## What Improved

By the end of the week, I became more comfortable with:

* Using Git and GitHub
* Organizing project files
* Writing documentation
* Building practical exercises
* Maintaining a learning journal
* Understanding the importance of consistent progress

## What I Will Improve Next

I want to become more confident with development workflows and continue building projects instead of focusing only on theoretical learning.

I also want to improve how I present my projects so that someone visiting my GitHub profile can quickly understand what I learned and what I built.

## Final Reflection

Week 1 taught me that a learning journey becomes more valuable when progress is documented.

My goal for the coming weeks is to keep learning, building, documenting, and improving consistently.
