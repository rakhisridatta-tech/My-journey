# Day 6 Journal - Web Basics (HTML/CSS)

Today I learned the basics of HTML and CSS. I understood that HTML is used to create the structure of a webpage, while CSS is used to style and improve its appearance.

I built my first styled webpage using separate index.html and style.css files. I created a header, a content section, a list of skills, a button, and a footer. I also learned how to connect an external CSS file to an HTML document.

While styling the page, I practiced using the CSS Box Model by applying margin, padding, borders, and border radius. I also used Flexbox to organize the page layout and make the design cleaner.

After completing the webpage, I updated my learning notes, organized the project folders, committed the changes using conventional Git commit messages, and pushed everything to GitHub.

## What I Learned
- HTML creates the structure of a webpage.
- CSS controls the design and appearance.
- The CSS Box Model consists of content, padding, border, and margin.
- Flexbox helps align and organize page elements.
- Keeping HTML and CSS in separate files makes the project more organized.

## Challenges
Initially, I was unsure about how to organize the HTML structure and connect the CSS file correctly. After practicing, I understood how both files work together to create a complete webpage.
