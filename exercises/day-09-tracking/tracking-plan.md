# Day 09 - Tracking Plan

## Funnel Events

### 1. page_view
- **Event:** page_view
- **When:** User visits the homepage.
- **Purpose:** Count website visitors.

### 2. hero_cta_click
- **Event:** hero_cta_click
- **When:** User clicks the main "Get Started" button.
- **Purpose:** Measure user interest.

### 3. lead_form_started
- **Event:** lead_form_started
- **When:** User begins filling out the contact form.
- **Purpose:** Track users who show intent.

### 4. lead_form_submitted
- **Event:** lead_form_submitted
- **When:** User successfully submits the form.
- **Purpose:** Measure completed leads.

## Funnel Flow

Page View
   ↓
Hero CTA Click
   ↓
Lead Form Started
   ↓
Lead Form Submitted
