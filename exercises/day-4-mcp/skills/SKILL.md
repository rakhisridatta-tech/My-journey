# Daily Journal Skill

When the user asks to create a daily journal:

1. Add today's date.
2. Write a short summary of what was learned.
3. Mention any challenges faced.
4. List the key takeaways.
5. Mention the next steps for tomorrow.

Format the response in Markdown.
