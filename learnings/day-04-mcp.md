# Day 4 – Skills & MCP

## What is a Claude Skill?

A Claude Skill is a reusable instruction that teaches Claude how to perform a specific task in a consistent way. It helps avoid writing the same prompt repeatedly.

## What does MCP let Claude do?

MCP (Model Context Protocol) allows Claude to connect with external tools, APIs, files, and applications. It extends Claude's capabilities beyond chatting by enabling it to interact with other systems securely.

## One Skill I'd Build for Tech Arion

I would build a Daily Progress Report skill. It would summarize the day's work, list completed tasks, mention blockers, and create a plan for the next day in a standard format.
