# Day 09 - PostHog + Meta Pixel

## What is PostHog?

PostHog is a product analytics platform that helps track user behavior on websites and applications. It collects event data to understand how users interact with a product and identify areas for improvement.

## What is Meta Pixel?

Meta Pixel is a tracking code provided by Meta (Facebook). It records visitor actions on a website, helping businesses measure ad performance, track conversions, and create custom audiences for advertising.

## What is a Funnel?

A funnel is a sequence of user actions that shows how visitors move toward a goal. It helps identify where users drop off and how to improve conversions.

### Example Funnel

1. Page View
2. Hero CTA Click
3. Lead Form Started
4. Lead Form Submitted

## Why Tracking Matters

Tracking helps businesses understand user behavior, improve website performance, optimize marketing campaigns, and increase conversions.
