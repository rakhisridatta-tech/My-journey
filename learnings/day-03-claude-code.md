# Day 3 - Claude Code Learning

## What is Claude Code?

Claude Code is an AI coding assistant that helps generate, edit, and improve code using natural language prompts. Instead of writing every line manually, we describe what we want, and Claude generates the code.


## What is Plan-First?

Plan-first means deciding what needs to be built before generating code.

Example:

- Decide the sections of the webpage.
- Choose colors.
- Decide responsiveness.
- Plan navigation.

Planning first helps reduce mistakes and makes the generated code more organized.

## Why Review Every Diff?

A diff shows the changes made to the code.

Reviewing every diff helps to:

- Understand what changed.
- Catch mistakes.
- Avoid deleting important code.
- Learn from AI-generated code.

Never accept AI changes without checking them.

## One Wrong Output and How I Fixed It

Initially, Claude generated a landing page that was not fully responsive.

To fix it, I gave another prompt asking Claude to improve the mobile layout and responsiveness.

## What I Learned

- Claude Code speeds up development.
- Good prompts produce better results.
- Planning before coding improves quality.
- Reviewing every change is important before accepting AI-generated code.
