# Day 6 - Web Basics (HTML/CSS)

## What HTML Does
HTML (HyperText Markup Language) is used to create the structure of a webpage.
It defines elements such as headings, paragraphs, images, links, buttons, and forms.
## What CSS Does
CSS (Cascading Style Sheets) is used to style HTML elements.
It controls colors, fonts, spacing, layouts, borders, animations, and responsiveness.
## The CSS Box Model
Every HTML element is treated like a box.
The box model consists of:
- Content
- Padding
- Border
- Margin
Content is the actual text or image.
Padding is the space inside the border.
Border surrounds the padding.
Margin is the space outside the border.
Example:
Content
↓
Padding
↓
Border
↓
Margin
## Flexbox
Flexbox is a CSS layout system used to align and distribute items.
Useful properties:
display: flex;
justify-content
align-items
flex-direction
gap
Flexbox makes it easy to build responsive layouts.
## What I Learned
- HTML creates webpage structure.
- CSS styles the webpage.
- The Box Model controls spacing.
- Flexbox helps arrange elements in rows and columns.
- Using separate HTML and CSS files makes code organized.
