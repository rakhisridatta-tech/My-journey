# Day 7 - Landing Pages (Tailwind)

## Topic
Landing Pages using Tailwind CSS

## What is a Landing Page?

A landing page is a web page created with a single objective, such as encouraging visitors to sign up, purchase a product, or explore a service.

## Anatomy of a High-Converting Landing Page

### Hero Section
The first section users see. It contains a compelling headline, supporting description, and a clear call-to-action button.

### Social Proof
Customer testimonials, ratings, achievements, or statistics help build trust and credibility.

### One CTA (Call to Action)
A landing page should focus on one main action such as "Explore Programs" or "Join Internship."

### Mobile Responsive Design
The page should provide a great experience on desktops, tablets, and mobile devices.

## What I Learned

- Tailwind CSS is a utility-first CSS framework.
- Responsive layouts are created using breakpoints like `md:` and `lg:`.
- Utility classes help build professional UIs without writing much CSS.
- Good landing pages have a clear structure with a hero section, features, social proof, and a strong call-to-action.
